# MPLADS Drishti

AI-Powered Monitoring Platform for the Members of Parliament Local Area Development Scheme (MPLADS).

## Structure
- `frontend/`: React/Vite web application
- `backend/`: Node.js Express API Gateway
- `ml_engine/`: Python FastAPI service for AI/ML tasks
- `database/`: PostgreSQL schemas and dummy data scripts

## Setup
Run `docker-compose up --build` to start all services.
